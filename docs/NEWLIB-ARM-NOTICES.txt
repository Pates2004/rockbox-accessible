Arm notices for the native Clip+ newlib math runtime
==================================================

These are the complete original notices from math_err.c and its included
math_config.h in newlib 4.4.0.20231231. The inspected native firmware links
math_err.o from Ubuntu's libm.a. Its selected newlib copyright collection
does not contain these Arm notices; this document supplies them in addition
to, not instead of, the other newlib notices.

Verified official source archive (read in memory; no upstream archive copy
or extracted source files are required alongside this notice):
https://sourceware.org/pub/newlib/newlib-4.4.0.20231231.tar.gz
Archive size: 9022406 bytes
Archive SHA-256:
0c166a39e1bf0951dfafcd68949fe0e4b6d3658081d6282f39aeefc6310f2f13

Paths below are relative to the archive's newlib-4.4.0.20231231 directory.
The source SHA-256 values identify the complete upstream files, not only
their notice blocks. Both original notice blocks are reproduced verbatim.
